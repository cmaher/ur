# ur_rpc (Shared RPC Contract)

Shared protobuf/tonic definitions between all crates. Changes here affect `ur`, `ur-server`, and `workercmd` binaries.

- Proto files live in `proto/` and are compiled by `build.rs` using `tonic-build`
- `retry::GrpcRetryPolicy` never retries a path in `retry::NEVER_RETRIED` (`LaunchWorker`, `LaunchLocalWorker`): a resent Launch could start a worker after its Stop (ur-ezhdb). No builderd client uses the retry service today (they use `RetryChannel::channel()`, which does not retry); keep Launch RPCs out of any retry that is added.
- All proto modules compile unconditionally. Only `stream` (optional tokio/tracing deps), `error` (optional tonic-types/anyhow deps), and `retry` (optional tower/tokio deps) are feature-gated
- All RPC types are generated by prost/tonic from `.proto` files — no hand-written request/response types
